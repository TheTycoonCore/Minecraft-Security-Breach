# Minecraft: Security Breach

A mashup mod bringing Minecraft survival mechanics, items, crafting, HUD overlays, and co-op/versus multiplayer into *Five Nights at Freddy's: Security Breach*.

## Features
- **Minecraft HUD Overlay**: Health, Hunger, Armor, and Hotbar interface.
- **Resource Gathering**: Break environmental objects across the Pizzaplex to harvest Wood, Iron, and materials.
- **Crafting & Weapons**: Craft swords, bows, tools, and barricades.
- **Multiplayer Modes**: 2–4 Player Co-op Survival and Survivor vs. Animatronic Versus Mode.

## Installation for Melty
Upload this repository link to Melty or place `MinecraftSecurityBreach_P.pak` into `fnaf9/Content/Paks/~mods/`.
